## 坑位提醒

- URL 必须带 `?fmt=ts2hls`，否则 404；`.smil/index.m3u8` 三段缺一不可。
- master 只 103 字节、里面只有一行 `01.m3u8?fmt=ts2hls,<数字>,...`，属正常，不是残缺。
- 同名多路（CCTV-1、江西都市、西藏/新疆/兵团卫视、金鹰卡通、国学、爱体育）已按带宽排序，
  低带宽的一条加 `(备)` 后缀，避免 App 按频道名去重时互相覆盖。
- 除主节点外的 6 条走不同 IP，`jx()` 里主机名是写死的，需要另加一个带 host 参数的变体方法。
